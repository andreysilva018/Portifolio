# Portfólio | Andrey Vinícius
Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades, projetos e objetivos profissionais na área de tecnologia.
O foco principal do portfólio é destacar minha transição para o desenvolvimento backend, com estudos e projetos voltados para Java, Spring Boot, APIs REST, SQL e integração com banco de dados.

## Sobre o projeto
Este portfólio foi desenvolvido com HTML, CSS e JavaScript, com layout responsivo e visual moderno.

A página apresenta:
- Apresentação profissional
- Experiência na área de TI
- Formação acadêmica
- Tecnologias estudadas
- Projetos desenvolvidos
- Certificações e cursos
- Links para contato, GitHub e currículo

## Tecnologias utilizadas:
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Devicon
- Google Fonts

## Objetivo:
O objetivo deste projeto é reunir em um único lugar minhas principais informações profissionais, projetos e estudos, servindo como apoio para processos seletivos e oportunidades na área de desenvolvimento backend.

## Perfil profissional:
Atualmente atuo na área de TI, com experiência em suporte técnico, análise de sistemas, identificação de inconsistências e entendimento de regras de negócio.
Estou direcionando meus estudos para desenvolvimento backend com Java, Spring Boot, APIs REST, SQL e banco de dados.
